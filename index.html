About

          
A bit of background

        

      

      

        

          
I'm a software development engineer at Mass Technologies. I build and own features across a multi-tenant hospital operations platform: FastAPI and PostgreSQL backends, React and TypeScript web apps, an Expo mobile app, and the AWS and GitHub Actions pipelines that release them. I built a design service for hospitals end to end, an on-device voice assistant for the mobile app, and a signed machine-to-machine API for a large medical device catalog.

          
Before that, I spent two years as a graduate researcher studying how misinformation about transgender and nonbinary communities spreads on TikTok, building a pipeline that processed over a million videos with GPU-accelerated video analysis, OCR, and topic modeling. I've also built real-time data pipelines on AWS, and taught machine learning as adjunct faculty through August 2026.

          
I'm an AWS Certified Solutions Architect. Outside of work I build things for fun — agent-orchestration tools, a terminal I can drive from my phone, small language models fine-tuned on niche datasets — mostly to see what breaks.

Payments Ledger Service

          
A double-entry ledger service with payment authorize, capture, void and refund, and idempotency keys so retries never move money twice. A transactional outbox publishes events to Kafka (Redpanda), and property tests and a k6 load test check that no money is created or lost. Three SLIs with 28-day error budgets, burn-rate alerts tested with promtool and a Grafana SLO dashboard. A scripted failure lab (Kafka down, Postgres restart, relay crash, poison event, Toxiproxy latency) with balance checks after each scenario. A dead-letter topic with once-only redrive. Rollback by image digest across an expand-and-contract Flyway migration, k6 SLO thresholds as a gate, an append-only caller audit log and a STRIDE review of the money path.

FHIR Analytics Pipeline

          
A pipeline for synthetic HL7 FHIR R4 records that validates and quarantines bad lines, pseudonymizes patients, loads DuckDB and builds dbt marts through an Airflow DAG. A k-anonymity check (k=5) before publishing, versioned HMAC pseudonymization keys with a rotation test, and a HIPAA-style control mapping. Pipeline metrics with a 06:00 freshness alert tested with promtool, a failure lab for corrupt input, schema drift, late updates and storage outage, and 108 tests.
