About

A bit of background

I'm a software development engineer at Mass Technologies, on a 10-person team building a multi-tenant hospital operations platform that has not launched yet. I own features end to end: FastAPI and PostgreSQL backends, React and TypeScript web apps, a React Native app for iOS and Android, and the GitHub Actions pipelines that release them. I designed the signed service-to-service API that every platform module uses, and built the hospital design service and the asset app.

Before that I spent two years as a graduate researcher studying how misinformation about transgender and nonbinary communities spreads on TikTok, with a pipeline that collected and analyzed over a million videos. I also taught Java and machine learning as adjunct faculty through August 2026.

Outside work I build public projects with tests and evidence: a payments ledger with SLOs and a failure lab, an agent platform with replay evals, a Rust webhook gateway and a Go inference service.
