Amazon CloudWatch Logs Insights & Centralized Logging

🕑 ~3 min read · 3 services covered
CloudWatch Logs Insights Log Subscription Filters Centralized Logging Account

Today's Concept

Logs Insights provides a query language over CloudWatch Logs for ad-hoc analysis without standing up separate infrastructure. Subscription filters stream logs in real time to a centralized logging account (via Kinesis Data Firehose/Streams) for org-wide search, retention, and SIEM ingestion.

Hands-on Lab / Practical Action (45 min)

Write a Logs Insights query extracting the top 10 slowest API requests in the last hour, then configure a subscription filter to forward ERROR-level logs to a central account.

Scenario Question Drills (20 min)

Q1. An organization wants every account's application logs centrally searchable in a dedicated logging account in near-real time. What's the mechanism?

A. Manually export logs nightly via S3
B. CloudWatch Logs subscription filters streaming to Kinesis Data Firehose in the central logging account
C. CloudTrail only
D. Increase log retention in each account
Correct answer: B. Subscription filters push log events in near-real time to a destination (commonly Kinesis Firehose/Streams) in a centralized account, enabling org-wide log aggregation.
